ZEBJUS DroneLab • offline setup help

Connect an AERION Kit

This local device page provides instructions only. Use the official HTTPS DroneLab WebApp for kit pairing and router setup. Do not type private device credentials here.

  1. Open DroneLab • MY KITS on your computer's normal Internet connection. Keep that tab open.
  2. Power the controller from regulated 5V. Join its ZEBJUS-AERION hotspot using your computer's Wi-Fi settings (factory-default AP password 12345678 unless changed).
  3. In MY KITS choose New Kit • Simple Connect → Find Kit on AP. The six-digit Kit Code and full Device ID are discovered automatically. Chromium Local Network Access permission may be required.
  4. If this browser has never been paired, connect the kit once by physical USB and choose Pair Once with USB. Then return to kit AP Wi-Fi and choose Find Kit on AP. On a personal computer you may opt in to Remember this browser.
  5. Choose Scan Wi-Fi, select a 2.4 GHz classroom router and enter its password only in the HTTPS WebApp. Choose Test & Save and verify the saved result, not merely an accepted request.
  6. Reconnect your computer to the classroom router. Choose Connect STA / Resume; full hardware Device ID and the authenticated response must match.

If browser local network access is blocked, use physical USB to configure the kit. The six-digit Kit Code and hotspot password are not permission credentials. Real motor output remains disabled in this diagnostic firmware.
