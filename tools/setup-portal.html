Connect your kit

  1. Open the official DroneLab WebApp before joining the kit hotspot.
  2. Join the kit AP using OS Wi-Fi settings. Return to the HTTPS tab and allow Local Network Access.
  3. Press Connect Kit. Device ID and Kit Code are detected automatically. No private label or pairing code is needed for AP diagnostics.

To configure a classroom router without USB: with the controller already running, hold its BOOT button for 3 seconds and release. Then Refresh Status, Scan Wi-Fi, select a 2.4 GHz router, and Test & Save in the HTTPS WebApp. Access expires after 5 minutes. Do not hold BOOT during power-on/reset. OTA and administration remain separately protected.

AP access is local bench diagnostics only. It does not grant teacher administration, OTA or motor arming. Router changes require temporary physical BOOT authorization. Anyone on the kit AP can access these diagnostics; use a private AP password in shared environments.
