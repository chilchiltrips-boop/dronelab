Connect your kit

  1. Open the official DroneLab WebApp before joining the kit hotspot.
  2. Join the kit AP using OS Wi-Fi settings. Return to the HTTPS tab and allow Local Network Access.
  3. Press Connect Kit. Device ID and Kit Code are detected automatically. No private label or pairing code is needed for AP diagnostics.

To configure a classroom router, connect to the Kit AP, then in the official HTTPS DroneLab WebApp choose Scan Wi-Fi, select a nearby 2.4 GHz router, enter the password and click Test & Save. No USB pairing, Private Label or BOOT button. OTA and teacher administration remain separately protected.

AP access is local bench diagnostics only. It does not grant teacher administration, OTA or motor arming. Router changes are available to clients joined to the Kit AP; choose a private AP password on shared networks. Anyone on the kit AP can access these diagnostics; use a private AP password in shared environments.
