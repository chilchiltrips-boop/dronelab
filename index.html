STA turns the kit hotspot off and tries saved routers. If every saved router fails, AP returns. Selecting AP keeps only the kit hotspot active until you choose STA. The header switch changes the kit mode; join the matching Wi-Fi on this computer and approve Connect when discovered.





On the Kit AP, click Connect Kit to enable Scan Wi-Fi and Test & Save immediately. Test & Save turns AP off while trying the router. Join the router on this computer and approve the discovered kit. AP returns if association fails. Router credentials save only after successful association.




STA credentials are saved only after successful router association. The header AP/STA switch selects connection transport; Apply Mode changes the ESP32 radio and can interrupt Wi-Fi. USB factory flashing is in Firmware & USB.
